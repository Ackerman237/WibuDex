8. PERUBAHAN ALLMANGA.JS
============================================================

Pada awalnya allManga.js masih menggunakan pola dari index.js.

Masalah yang ditemukan pada versi gabungan:
- DOMContentLoaded dibuat dua kali.
- Fungsi goToPage dibuat dua kali.
- Event listener search dibuat dua kali.
- prevBtn dan nextBtn digunakan sebelum deklarasi.
- currentPage belum dibuat.
- loadManga selalu request page=1.
- Kurung tutup tidak seimbang.
- Ada kode duplikat.

Solusi:
Isi allManga.js disederhanakan dan dirapikan.

Konfigurasi utama:

const currentLimit = 50;

Page dibaca dari URL:

const urlParams =
  new URLSearchParams(window.location.search);

let currentPage =
  parseInt(urlParams.get('page')) || 1;

Query pencarian juga dibaca dari URL:

let currentQuery =
  urlParams.get('query') || '';

Request API kemudian menggunakan:

/api/manga?page=${page}&limit=50

Contoh:

Page 1:
GET /api/manga?page=1&limit=50

Page 2:
GET /api/manga?page=2&limit=50

Page 3:
GET /api/manga?page=3&limit=50

============================================================
9. FUNGSI PAGINATION
============================================================

Fungsi goToPage digunakan untuk berpindah halaman.

Konsep:

function goToPage(page) {
  if (page < 1) return;

  const params =
    new URLSearchParams();

  params.set('page', String(page));

  if (currentQuery) {
    params.set('query', currentQuery);
  }

  window.location.href =
    `/doujinPage/html/allManga.html?${params.toString()}`;
}

PREVIOUS:
- Hanya aktif jika currentPage > 1.

NEXT:
- Mengarahkan ke currentPage + 1.

PREVIOUS:
- Mengarahkan ke currentPage - 1.

Page indicator menampilkan:

PAGE 1
PAGE 2
PAGE 3
dan seterusnya.

============================================================
10. PAGINATION DAN SEARCH
============================================================

Search tetap menggunakan halaman yang sama.

Contoh:

allManga.html?page=1&query=naruto

Ketika user melakukan search:
- Page dikembalikan ke 1.
- Query disimpan di URL.

Contoh:

?query=naruto&page=1

Dengan konsep tersebut:
- Refresh tidak menghilangkan posisi pencarian.
- Browser back/forward lebih natural.
- URL dapat dibookmark.

============================================================
11. LOGIKA NEXT BUTTON
============================================================

Ditambahkan logika:

nextBtn.disabled =
  mangaList.length < currentLimit;

Tujuan:
Jika jumlah manga yang diterima kurang dari 50,
halaman dianggap sebagai halaman terakhir.

Contoh:

Page 1 → 50 manga
Page 2 → 50 manga
Page 3 → 23 manga

Maka di Page 3:
NEXT dinonaktifkan.

Catatan:
Logika ini perlu diperhatikan untuk search karena backend juga melakukan filtering terhadap hasil pencarian.
